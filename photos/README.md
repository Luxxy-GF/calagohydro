# Screenshot assets

The root README links to these PNG files using relative paths. Replace an image with your own screenshot using the same filename to update the gallery. Add a new PNG here and a Markdown image link in the root README for another page.

Desktop images use a 1440 × 960 viewport. Mobile images use 390 × 844. Capture only demo data or redact private information before adding your own screenshots.

Regenerate the included demo captures with `scripts/screenshots.cjs`; prerequisites and commands are in [DEVELOPMENT.md](../DEVELOPMENT.md).

Included pages: servers, console, files, databases, network, backups, users, schedules, startup, settings, server activity, account, API keys, SSH keys, account activity, admin overview and login. Mobile captures cover console, files, account, admin and login.
